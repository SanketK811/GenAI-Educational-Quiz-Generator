# 🧠 AI-Powered Educational Quiz Generator

A simple web application built with **Python** and **Streamlit** that creates
multiple-choice quizzes on any topic or from an uploaded text file.

It works in two modes:

| Mode | When it is used | What happens |
|------|-----------------|--------------|
| 🤖 **AI mode** | An OpenAI API key is provided | Questions are generated by AI from your topic or file |
| 📚 **Demo mode** | No API key is provided | Built-in sample questions are used, so the app still works |

---

## ✨ Features

- Enter a **topic** or upload a **`.txt` file** as source material
- Generates **5 to 10** multiple-choice questions
- Every question has **4 options (A, B, C, D)**
- Students select their answers using radio buttons
- **Submit** button calculates the result
- Shows **score**, **percentage**, status and performance feedback
- Shows the **correct answer** and a short **explanation** for every question
- Clean, user-friendly Streamlit interface
- Runs completely **offline** when no API key is available

## 🚀 How to Run

### 1. Install Python

Install **Python 3.9 or newer** from <https://www.python.org/downloads/>.
During installation, tick **"Add Python to PATH"**.

Check the installation:

```bash
python --version
```

### 2. Open a terminal in the project folder

```bash
cd path/to/004
```

### 3. (Recommended) Create a virtual environment

**Windows (PowerShell):**

```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

**Windows (Command Prompt):**

```cmd
python -m venv venv
venv\Scripts\activate.bat
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install the dependencies

```bash
pip install -r requirements.txt
```

### 5. Start the app

```bash
streamlit run app.py
```

Streamlit will open the app in your browser (usually
<http://localhost:8501>).

## 🔑 Enabling AI Mode (Optional)

You can run the app without any API key. To generate fresh questions with AI,
provide an OpenAI API key in **either** of these ways:

**Option A – Enter it in the app sidebar**

Paste the key into the *OpenAI API key* box in the left sidebar.

**Option B – Use an environment variable**

Windows (PowerShell):

```powershell
$env:OPENAI_API_KEY = "sk-your-key-here"
streamlit run app.py
```

Windows (Command Prompt):

```cmd
set OPENAI_API_KEY=sk-your-key-here
streamlit run app.py
```

macOS / Linux:

```bash
export OPENAI_API_KEY="sk-your-key-here"
streamlit run app.py
```

**Optional settings**

- `OPENAI_MODEL` – model name (default: `gpt-4o-mini`)
- You can also place the key in `.streamlit/secrets.toml`:

  ```toml
  OPENAI_API_KEY = "sk-your-key-here"
  OPENAI_MODEL = "gpt-4o-mini"
  ```

If the API call fails for any reason (wrong key, no internet, quota), the app
automatically falls back to the built-in sample questions and shows a warning.

## 🎓 How to Use

1. Type a topic (for example, *Python functions* or *DBMS normalization*), **or**
   upload a `.txt` file such as `sample_notes.txt`.
2. Choose the number of questions in the sidebar.
3. Click **✨ Generate Quiz**.
4. Select one option for each question.
5. Click **✅ Submit Answers**.
6. View your score, percentage and feedback, then read the explanation for
   each question.
7. Click **🔄 Start a New Quiz** to try again.

---

## 🧪 Quick Test Without an API Key

1. Run `streamlit run app.py`.
2. Type `Python` in the topic box.
3. Click **Generate Quiz**.
4. The app uses the built-in *Python Programming* question bank.

You can also upload `sample_notes.txt` and the app will pick the most relevant
question bank based on the text.

## 🛠️ Troubleshooting

| Problem | Solution |
|---------|----------|
| `streamlit: command not found` | Activate the virtual environment, then run `pip install -r requirements.txt` |
| `ModuleNotFoundError: streamlit` | Run `pip install streamlit` |
| AI questions are not generated | Check that an API key is entered and the `openai` package is installed |
| `Invalid API key` warning | Verify the key and that your OpenAI account has available credit |
| Nothing happens on Generate | Make sure you entered a topic or uploaded a non-empty text file |

---

## 📝 Notes

- Only `.txt` and `.md` files are supported for upload.
- The app sends the topic/text to OpenAI **only** when you use AI mode.
- The API key is used in memory for the request and is not saved to disk by
  this app.
